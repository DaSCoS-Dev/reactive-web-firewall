# Contributing

Keep the immediate path conservative. New signatures must be deterministic, covered by tests and documented with false-positive analysis. Broader reputation or threshold logic belongs outside the millisecond watcher.

Run:

```bash
./tests/check-syntax.sh
./tests/self-test.sh
```

Do not commit private keys, production IPs, domains, blocklists, Apache VirtualHosts or packet captures.
